## 활동 기록

### 목록 조회

- 요청: `GET /api/activities`
- 성공: `200`

```json
[{"id": 1, "title": "10월 해커톤 참가", "content": "교내 해커톤에 4명이 참가했습니다.", "activityDate": "2026-10-15"}]
```

### 상세 조회

- 요청: `GET /api/activities/{id}`
- 성공: `200`
- 실패: `404` 해당 번호의 활동 기록이 없음

### 등록

- 요청: `POST /api/activities`
- 보낼 내용: 제목(필수, 100자 이하), 내용(선택, 3000자 이하), 활동 날짜(필수, 오늘이나 과거, `YYYY-MM-DD` 형식)

```json
{"title": "10월 해커톤 참가", "content": "교내 해커톤에 4명이 참가했습니다.", "activityDate": "2026-10-15"}
```

- 성공: `201` 번호가 붙은 활동 기록이 돌아옴
- 실패: `400` 입력값 검증 실패 (빈 제목, 미래 날짜 등), `400` 요청 형식 오류 (잘못된 날짜 형식 등)

### 수정

- 요청: `PUT /api/activities/{id}`
- 보낼 내용: 등록과 같음
- **주의**: 수정은 통째로 바꿉니다. 보내지 않은 항목은 비워집니다. 바꾸지 않을 항목도 기존 값을 그대로 다시 보내주세요.
- 성공: `200`
- 실패: `400` 입력값 검증 실패 또는 형식 오류, `404` 해당 번호의 활동 기록이 없음

### 삭제

- 요청: `DELETE /api/activities/{id}`
- 성공: `204`
- 실패: `404` 해당 번호의 활동 기록이 없음
