# 동아리 홈페이지 API

## 기본 정보

- 로컬 주소: `http://localhost:8080`
- 요청과 응답은 JSON 형식

## 에러 응답 형식

모든 에러는 아래 모양으로 돌아옵니다.

```json
{"status": 404, "message": "4번 공지사항을 찾을 수 없습니다.", "errors": {}}
```

입력값 검증에 실패하면 `errors`에 칸별 이유가 담깁니다.

```json
{"status": 400, "message": "입력값이 올바르지 않습니다.", "errors": {"title": "제목을 입력해주세요."}}
```

## 공지사항

### 목록 조회

- 요청: `GET /api/notices`
- 성공: `200`

```json
[{"id": 1, "title": "10월 정기모임 안내", "content": "10월 30일 저녁 7시에 모입니다."}]
```

### 상세 조회

- 요청: `GET /api/notices/{id}`
- 성공: `200`

```json
{"id": 1, "title": "10월 정기모임 안내", "content": "10월 30일 저녁 7시에 모입니다."}
```

- 실패: `404` 해당 번호의 공지사항이 없음

### 등록

- 요청: `POST /api/notices`
- 보낼 내용: 제목(필수, 100자 이하), 본문(필수, 3000자 이하)

```json
{"title": "11월 정기모임", "content": "11월 6일 저녁 7시에 모입니다."}
```

- 성공: `201` 번호가 붙은 공지사항이 돌아옴

```json
{"id": 5, "title": "11월 정기모임", "content": "11월 6일 저녁 7시에 모입니다."}
```

- 실패: `400` 입력값 검증 실패

### 수정

- 요청: `PUT /api/notices/{id}`
- 보낼 내용: 등록과 같음 (제목과 본문 모두 보내야 함)
- 성공: `200` 수정된 공지사항이 돌아옴
- 실패: `400` 입력값 검증 실패, `404` 해당 번호의 공지사항이 없음

### 삭제

- 요청: `DELETE /api/notices/{id}`
- 성공: `204` 돌려주는 내용 없음
- 실패: `404` 해당 번호의 공지사항이 없음
